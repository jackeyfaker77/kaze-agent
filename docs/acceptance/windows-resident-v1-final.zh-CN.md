## 用户重启步骤

1. 正常重启 Windows，登录当前用户。不要打开 Kaze 客户端，不手动启动第二个 Host，不改代理、渠道或模型设置。
2. 等待后台启动约 2–3 分钟，向原 Telegram 私聊发送一次：`TG-WINV1-FINAL-20261030，请不要调用工具，只回复：Windows 常驻最终验收正常。`
3. 收到回复后回到本聊天说明“已重启、未打开客户端、已收到回复”，并说明收到几条。没有回复时直接报告，先不要反复发送。
4. 等后台身份及历史核对通过，再由验收操作创建一个唯一命名、几分钟后到期的测试待办；用户不需重复创建。收到提醒后确认数量，不必回复机器人。
